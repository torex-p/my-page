# エアコンクリーニング 予約フォーム

株式会社トレックスパートナーズのエアコンクリーニング予約フォームです。

- `index.html`：予約フォームのページ本体（GitHub Pages で公開）
- `gas/Code.gs`：予約を受け付ける Google Apps Script（スプレッドシートへの記録とメール送信）

## 予約の流れ

1. お客様がフォームを送信する
2. スプレッドシートの「予約一覧」シートに1行追加される（対応状況は「未対応」）
3. 社内に通知メールが届く
4. お客様に受付確認メールが届く

## 料金を変えるとき

`index.html` の下の方にある `CONFIG.prices` の数字を書き換えます（単位は円、税込）。

| 項目 | キー |
|---|---|
| 通常の壁掛けエアコン 1台 | `standard` |
| お掃除機能付き 1台 | `auto` |
| 防カビ・抗菌コート 1台あたり | `antiMold` |
| 室外機クリーニング 1台あたり | `outdoor` |
| ドレンホース洗浄 1台あたり | `drain` |

## 受付スクリプトの設定（最初の1回だけ）

1. 予約を記録する Google スプレッドシートを開く
2. メニューの「拡張機能 → Apps Script」を開き、`gas/Code.gs` の中身を貼り付けて保存
3. 「デプロイ → 新しいデプロイ」で種類を「ウェブアプリ」にし、
   - 次のユーザーとして実行：自分
   - アクセスできるユーザー：全員
   にしてデプロイ（初回は Google アカウントの権限確認が出ます）
4. 表示されたウェブアプリの URL を、`index.html` の `CONFIG.endpoint` に貼り付ける

## 差し替えが必要な箇所

- 電話番号：`index.html` のフッターと `gas/Code.gs` の `companyTel`（現在は `00-0000-0000`）
- 料金：現在は仮の金額
